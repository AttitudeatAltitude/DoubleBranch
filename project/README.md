# Project

How the website project is run.

- `roadmap.md` — the phases and where we are now.
- `backlog.md` — every task, who it's on, what's blocked, and proposed
  ideas not yet agreed.
- `decisions-needed.md` — decisions waiting on Kevin or the
  leadership team, each with a recommendation. The leadership list is
  at the top.
- `decisions-log.md` — what was decided, by whom, and why.
- `approvals-log.md` — leadership sign-offs on site content.
- `session-log.md` — what each work session did.
- `next-steps.md` — the next 1–3 moves.
- **Tracker** (Kevin's status board, outside the repo):
  https://claude.ai/artifact/Lp771qVc4DGzWEckWZH3gB. Answers, ticks
  and notes typed there are copied into these files each session.
- `CLAUDE.md` — standing instructions for Claude.
