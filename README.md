# Double Branch Baptist Church — Website Project

Building a first website for Double Branch Baptist Church (Poteau, OK),
for both the congregation and first-time visitors. Claude acts as
project manager and builder; the church leadership team approves content
before it goes public.

## Folders

- `project/` — the plan: roadmap, backlog, decisions waiting on someone,
  approvals, and a session log. **Start with `project/next-steps.md`.**
- `church/` — the church's facts (service times, beliefs, ministries,
  events, streaming). Single source of truth for the site.
- `docs/` — the website itself (GitHub Pages publishes from this
  folder; the name is a GitHub convention).

## Rules of thumb

- Everything in this repo is written as if it were public. No personal
  contact details, prayer requests, or photos of identifiable children.
- Facts change in `church/` first, then on the site.
- `CLAUDE.md` files are standing instructions for Claude.
