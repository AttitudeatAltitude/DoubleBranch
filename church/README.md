# Church

The facts the website is built from. Each fact is marked confirmed,
unconfirmed, or unknown.

- `facts.md` — name, address, service times, contact, people, online
  presence.
- `beliefs.md` — statement of faith in the church's own words.
- `ministries.md` — Sunday school, youth, men's, women's, children.
- `events.md` — upcoming and recurring events.
- `media.md` — livestream setup and the streaming upgrade plan.
- `audio-guide.md` — step-by-step sermon audio recording on the
  soundboard.
- `sources-log.md` — where each piece of information came from.
- `CLAUDE.md` — standing instructions for Claude.
